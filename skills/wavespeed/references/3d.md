# 3D Asset Generation Models on WaveSpeedAI

## Popular Models

| Model ID | Type | Notes |
|----------|------|-------|
| `wavespeed-ai/meshy` | text-to-3d | Generate 3D models from text |
| `wavespeed-ai/meshy-image-to-3d` | image-to-3d | Generate 3D from reference image |

## Common Parameters

```json
{
  "prompt": "A wooden chair with curved armrests",
  "style": "realistic"
}
```

## Example: Text-to-3D

```bash
curl -X POST https://api.wavespeed.ai/api/v3/wavespeed-ai/meshy \
  -H "Authorization: Bearer $WAVESPEED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A medieval fantasy sword with glowing runes"}'
```

Result URL at `data.outputs[0]` — typically a .glb or .obj model download.
